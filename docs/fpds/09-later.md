# FPDS — Not designed yet

These areas are part of FPDS but have not been designed. Until each is written, a
builder answers any request that needs it with the gap message in `00-protocol.md`
(the *Missing component* field names the area below). They will be added one by one,
each with its own rules, spec cards and checks (Pavan, 2026-10-23).

| Area | What it will cover | Until then |
|---|---|---|
| **UX copy** | Voice and tone, labels, button verbs, statement lines, confirmations, errors, toasts beyond the one-line rule, number/date/plural formats as a writing guide | Follow the copy already on the reference pages and `07-ux-rules.md`; anything new is a gap |
| **Empty pages & empty states** | First use, no records, no results, no permission, error, offline — per page type and per unit | Use the Empty state molecule exactly as the reference pages do; anything else is a gap |
| **Highlight units** | Everything that draws attention — banners, recommendations, awaiting pills, running-late cues, new-item marks — as one family with ranking rules | Use the Alert banner unit and the Status & awaiting pills; anything else is a gap |
| **Illustrations** | Style, palette, where they are allowed (likely empty states and onboarding) | None are used; any request for one is a gap |
